# 《F4_F3接口映射协议 v1.0》

## 1. 文档目的

定义：

F4 教案优化系统

与

F3 课堂模拟系统

之间的数据转换规则。

目标：

实现：

```
F4 current-state
        ↓
F4-F3 Adapter
        ↓
F3 Classroom Simulation API
```

------

# 2. 系统关系

```
                 F4
        教案优化/版本管理

                |
                |
        current-state API

                ↓

        F4-F3 Adapter

                ↓

             F3 API

                ↓

          Classroom Simulation

                ↓

        课堂过程/反馈结果
```

------

# 3. F4 输出数据

接口：

```
GET /api/sessions/{session_id}/current-state
```

主要使用：

```
{
 "sections":[]
}
```

单个 section：

```
{
"id":"xxx",

"title":"新知探究",

"order_index":3,

"section_type":"exploration",

"current_content":"教师引导学生探索..."
}
```

------

# 4. F4 → F3 过滤规则

## 保留类型

进入课堂模拟：

```
CLASSROOM_SECTION_TYPES = ["introduction","exploration","teaching_process","practice","summary"]
```

------

## 排除类型

不进入：

```
["objectives","learning_analysis","key_difficulties","preparation","assessment","homework","board"]
```

原因：

这些属于教案描述信息，不属于课堂运行过程。

------

# 5. F3 输入格式设计

F3 API：

## 创建课堂模拟

接口：

```
POST /api/classroom/start
```

请求：

```
{
 "lesson_id":"001",

 "materials":[

    {
      "id":1,

      "title":"新知探究",

      "teaching_script":
      "教师引导学生探索数字编码规律",

      "key_points":[
          "编码规则",
          "数字含义"
      ]
    }

 ]
}
```

字段说明：

| 字段            | 来源                    |
| --------------- | ----------------------- |
| lesson_id       | F4 session              |
| materials       | Adapter生成             |
| title           | section.title           |
| teaching_script | section.current_content |
| key_points      | 后续可由LLM提取         |

------

# 6. F4→F3转换规则

伪代码：

```
def convert_section(section):    return {        "id":        section["order_index"],        "title":        section["title"],        "teaching_script":        section["current_content"],        "key_points":[]    }
```

# 7. F3 API设计

## 7.1 启动课堂

### POST

```
/api/classroom/start
```

输入：

```
{
"materials":[]
}
```

输出：

```
{
"session_id":"xxx",

"status":"started"
}
```

------

## 7.2 发送课堂消息

### POST

```
/api/classroom/message
```

输入：

```
{
"session_id":"xxx",

"message":"学生回答"
}
```

输出：

```
{

"speaker":"teacher",

"function":"teach",

"content":"教师回复内容"

}
```

------

## 7.3 获取课堂状态

### GET

```
/api/classroom/{session_id}/state
```

输出：

```
{

"dialogue":[
 {
  "speaker":"teacher",
  "content":"..."
 }
],


"current_material":1

}
```
