## 我的任务定位

我与绵绵以 **Paper#4：多智能体教案撰写与优化 Pipeline** 为主线；同时与语洁、Tten 对接 Paper#3 课堂模拟，并参与四个方向的 Web 作品化。现阶段以 Paper#4 为优先，Paper#3 联动和整体作品集成分阶段推进。

## 目前进展

1. **基础流程已实现并真实运行。** 系统从教学任务生成教案，经学科内容、教学法、目标—活动—评价对齐三个角度提出意见，再对意见进行校验、质量判断和定向改写；支持迭代、版本及修改记录，并导出 JSON、Markdown、Word。这里的 Agent 使用真实模型，不是预置教案或 Mock 结果。
2. **完成初步作品化接入。** 现有网页支持输入教学信息生成教案、上传 Word 原稿进行优化、查看任务进度和下载结果。生成与优化各完成过一次真实模型闭环测试；这是工程可用性验证，不等于教学效果得到证明。
3. **已暴露下一阶段研究问题。** 目前角色虽有分工，但“不同知识配置是否更有效”“多轮批评何时值得继续”“对抗/辩论机制是否带来真实质量提升”，仍需通过对照实验回答，不能仅依据系统内部 Judge 分数下结论。

## 接下来怎么做

- **先建立评价基线：** 选定同一批教案任务、输入材料和评价量表，保留初稿、每轮意见、改写稿与人工评价，比较单轮/多轮、不同 Critic 配置及知识配置；优先解决内容空泛、依据不足和重复改写等问题。
- **同步推进论文准备：** 阅读教案生成、多智能体批评与教育评价相关论文，整理已有方法、可借鉴机制与本项目的研究问题，逐步形成综述和 Paper#4 实验方案。
- **再做 Paper#3 联动：** 与语洁、Tten 对齐教案输入格式和课堂模拟反馈格式，先让模拟结果作为教案的后验证据，再讨论是否进入下一轮改写。
- **继续完善 Web：** 与作品化同学对齐数据格式和展示需求，但不让页面开发替代 Paper#4 的质量实验。
