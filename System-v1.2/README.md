# 教案智能批注系统

> 一个本地运行的教学设计（教案）智能评分与批注工具。
> 上传一份教案，系统会用**你提供的评分标准**逐维度打分，并给出**逐条批注 + 具体改进建议**。

---

## 一、这个工具能做什么

- 📊 **按维度评分**：教学内容、教学目标、学情分析、过程设计、课程思政、评价反馈等 12 个维度，逐项打分并给出理由
- ✍️ **逐条批注**：指出教案中的具体问题，标注「位置 + 原文引用 + 分析 + 建议 + 依据来源」
- 💡 **改进建议**：结合课程标准、教学法理论给出"怎么改"的具体建议
- 📄 **多种产物**：
  - 批注报告（Word，便于阅读）
  - **已批注 Word**（在你上传的教案上加 Word 原生批注气泡）
  - **已批注 PDF**（在 PDF 教案上高亮原文 + 批注气泡）
  - 评分清单（JSON / Markdown，便于统计）
- 🔄 **两种评分标准**：竞赛标准（田家炳杯）、学生自制标准，可在界面切换
- 🧮 **支持学科**：数学、英语（其他学科需要补充标准与知识库）

## 二、快速开始（约 10 分钟）

### 第 1 步：安装 Python（已装可跳过）

1. 打开 <https://www.python.org/downloads/>
2. 点击黄色的 **Download Python 3.x** 按钮下载安装包
3. 运行安装包，**务必勾选底部的 `Add Python to PATH`**（这一步最容易漏，漏了后面会报错）
4. 一路 Next 完成安装

> 验证是否装好：按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入 `python --version`，
> 能看到版本号（如 `Python 3.12.0`）就成功了。

### 第 2 步：安装依赖（只需做一次）

打开本项目文件夹，在地址栏输入 `cmd` 回车，然后执行：

```bat
python -m pip install -r requirements.txt
```

> 如果下载很慢或失败，换成国内镜像：
> ```bat
> python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 第 3 步：获取 API Key

系统需要调用大模型（DeepSeek）来评分，需要一个 API Key：

1. 打开 <https://platform.deepseek.com>，注册并登录
2. 左侧「API Keys」→ 创建新的 Key，复制它（形如 `sk-xxxxxxxx`）
3. 在「充值」页充少量金额（评一份教案约几分钱）

### 第 4 步：启动系统

**双击项目里的 `start_web.bat`**（首次运行会自动检查依赖，约 10 秒后浏览器自动打开）。

> 如果没有自动打开，手动在浏览器访问：<http://localhost:8501>
> 用完直接关掉那个黑色命令窗口即可停止服务。

### 第 5 步：填写 API Key（仅首次）

1. 在网页**左侧菜单**点「⚙️ 设置」
2. 把复制的 API Key 粘贴到输入框，点「💾 保存」
   - 保存后会写入项目里的 `data/.api_key`，**以后启动不用再填**
   - 可以点「🔌 测试连接」验证是否可用

### 第 6 步：开始评分

1. 左侧菜单点「📝 教案评分」
2. **放入教案**（二选一）：
   - 把教案文件（`.docx` 或 `.pdf`）放到 `data/plans/` 文件夹，然后在页面上选择
   - 或直接在页面上「上传新文件」
3. 选择**评分标准**（竞赛 / 学生）
4. 点「🚀 开始评分」，等待约 2 分钟
5. 页面下方查看评分结果，并可下载各种产物

## 四、常见问题

### Q1. 双击 `start_web.bat` 一闪而过 / 提示"不是内部或外部命令"

说明没装 Python 或没勾选 `Add Python to PATH`。重新安装 Python 并勾选该选项。

### Q2. 安装依赖报错 / 特别慢

换用清华镜像源：

```bat
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3. 页面打不开（浏览器显示无法访问）

- 确认那个黑色命令窗口还在运行（关掉窗口 = 停止服务）
- 确认地址是 `http://localhost:8501`
- 如果提示端口被占用，可关闭之前遗留的窗口后重试

### Q4. 提示"未配置 API Key"

到「⚙️ 设置」页填写并保存（见第 5 步）。保存后若仍提示，刷新页面重试。

### Q5. 评分很慢

- 普通 Word / PDF：约 1-3 分钟一份
- **扫描版 PDF**（整页图片、不能选中文字）：需要先做 OCR 识别，可能 5-10 分钟一份

> ⚠️ 如果提示缺少 OCR 组件（如 `No module named 'easyocr'`）：
> 请阅读 **`docs/OCR安装与使用说明.md`**（含"去哪装 / 装到哪 / 怎么用"完整流程），
> 或直接双击 **`tools\install_ocr.bat`** 一键安装（约 2GB，只在确有扫描版教案需要评时才装）。

### Q6. 没有生成"已批注 PDF"

只有 PDF 教案会生成"已批注 PDF"；Word 教案会生成 **"已批注 Word"**（效果类似，用 Word 打开可看到右侧批注）。
另外，**扫描版 PDF 无法高亮原文**（因为没有文本层），批注会以文档末尾便签形式给出。

### Q7. 评分结果不理想 / 分数偏高偏低

系统用"锚点库"（从大量真实教案归纳的档位特征）校准分数。如需调整：

- 评审方式已固定为 v2（对应 `config.yaml` 的 `prompt.default_variant`），如需更换可修改该配置
- 关闭/开启锚点注入：`config.yaml` 的 `anchors.enabled`

## 六、进阶用法（命令行）

习惯命令行的话，可以不用网页：

```bat
python pipeline.py --list                     :: 列出可用教案 / 标准 / 示例
python pipeline.py --plan "教案.docx" --criteria competition --suggest
```

参数说明：

| 参数 | 含义 |
|------|------|
| `--criteria competition` | 使用竞赛标准（`student` 为学生标准） |
| `--suggest` | 额外生成"细化建议"（多一次调用，约 +40 秒） |
| `--variant v3_strict` | 使用严格评审风格 |
| `--batch` | 批量评分 `data/plans/` 下所有教案 |
| `--dry-run` | 只生成提示词、不调用模型（用于调试） |

## 九、关于重命名（可自由改包名）

**这个文件夹可以随便改名**（中文名也行，如「教案批注系统v1.0」）——系统内部所有路径都是
按"文件自己所在的位置"推算的，与文件夹叫什么无关。已实测：改成中文名后功能完全正常。

| 可以改 | 不能改（改了程序会找不到文件） |
|--------|--------------------------------|
| ✅ 外层文件夹名（解压后的目录名） | ❌ 内部子目录名：`data/`、`knowledge_base/`、`output/`、`web/`、`tools/`、`docs/`、`samples/` |
| ✅ 压缩包（.zip）的文件名 | ❌ 内部文件名：`pipeline.py`、`config.yaml`、`start_web.bat`、`web/app.py` 等 |

**建议**：包名尽量**不要带空格**（用「教案批注系统v1.0」而不是「教案批注 系统 v1.0」）——
带空格通常也能跑，但个别 Windows 环境处理命令行空格时可能有差异。

**操作步骤**：

1. 把 `BiaoZhu-v1.0.zip` 解压
2. 直接对解压出来的文件夹重命名（如 `教案批注系统v1.0`）
3. 进入文件夹，照常双击 `start_web.bat` 使用

> 若想连"压缩包解压出来的名字"一起改：解压 → 重命名文件夹 → 重新压缩成 zip。
