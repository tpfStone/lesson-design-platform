# 粗评数据整理归纳 — 交接说明（给同学）

> 这份说明 + 配套文件，是"教案智能批注系统"粗评阶段的任务交接。
> 你的角色：**粗评结果的分析整理者**，产出"评分分数段锚点"的初稿。

---

## 一、背景（30 秒看懂）

我们开发了一个自动批注教案的系统：输入教案 → 按 12 个维度打分（教学内容、教学理念、学情分析、教学目标、教学资源、教学方法、过程设计、课程思政、课堂互动、评价反馈、版式观感、文档规范）→ 输出分数和批注。

现在要做的事：让评分**更精确**——给每个维度、每个分数段都配上"真实教案原文示例 + 该分数段的共性特征"，这样 AI 评分时有具体参照物，而不是凭感觉打分。

**你负责的就是"从粗评数据中提炼分数段模板"这一步。**

## 三、JSON 数据怎么读

`数学_粗评精简.json` 结构：

```json
{
  "学科": "数学",
  "标准": "competition",
  "教案数": 9,
  "教案": [
    {
      "教案": "《异分母分数加、减法》教学设计 张凤敏",
      "年级": "五年级下册",
      "总分": 63,
      "维度": [
        {
          "维度名称": "教学内容",
          "满分": 10,
          "得分": 8,
          "得分理由": "对教材地位、前后联系分析深入...",
          "批注": [
            {
              "位置": "一、（二）",
              "原文引用": "教案里的原句",
              "评价": "达标",
              "具体分析": "这段为什么得这个评价"
            }
          ]
        }
      ]
    }
  ]
}
```

**要点**：`原文引用` 字段是直接从教案里摘的句子——它就是你提炼"分数段示例"时要挑选/引用的原文素材。

## 四、你要做的任务（分 5 步）

### 第 1 步：分档（规则已定，直接套用）

每个维度按 **得分/满分 的比例** 分 4 档：

| 档 | 判定 | 相当于（满分10） | 相当于（满分5） |
|----|------|------|------|
| Q1 低分段 | 得分 < 满分的 25% | 0-2 分 | 0-1 分 |
| Q2 中低段 | 25% ≤ 得分 < 50% | 3-4 分 | 2 分 |
| Q3 中高段 | 50% ≤ 得分 < 75% | 5-7 分 | 3 分 |
| Q4 高分段 | 得分 ≥ 75% | 8-10 分 | 4-5 分 |

> 边界规则：正好 25% / 50% / 75% 归**高一档**（如 5/10=50% 归 Q3）。
> 满分 20 的过程设计按同比例：Q1<5、Q2 5-9、Q3 10-14、Q4 15-20。

### 第 2 步：统计覆盖

对每个学科、每个维度，统计 4 个档各有几份样本。结果填进模板的"样本数"行。
**哪些档是空的 → 标注"样本不足"，不要硬编。**

### 第 3 步：提炼共性特征（核心工作）

对"维度×档位 **有样本**"的组合（如"教学内容 Q4 有 5 份"）：

1. 把这 5 份教案在该维度的 `得分理由` + `批注[].具体分析` 读一遍
2. 找出它们**共同具备的特征**（"因为做到了 X，所以给高分"）
3. 用 2-4 句话写"该分数段的共性特征描述"——**要求：换一份陌生教案，也能按这个描述判断它该不该归这档**（即特征要可判断、不空泛）

共性特征的反例 ❌："教案整体质量较好"
共性特征的正例 ✅："教材分析点明本课时在单元中的地位与前后知识联系，重难点表述具体且与学情匹配"

### 第 4 步：挑选代表性原文（每档 1-2 段）

从该档样本的 `批注[].原文引用` 中，挑 1-2 段**最能代表该档水平**的教案原文，填入模板。

规则：
- 原文必须是教案真实句子，**一字不改**（可直接从 JSON 复制）
- 宁缺毋滥——拿不准就不选，标"见某教案"，不要编造

### 第 5 步：产出模板文件

把第 2-4 步结果填入 `分数段锚点模板_XX.md`（每个维度一节、每档一段），这就是你的交付物。

## 五、低分候选文件的用途

`低分候选_*.md` 是每维度分数**最低的 4 份**样本。它是给**研究生人工复核**用的（确认这些是不是真的低分、修正分数）。

你处理它时：
- 可以借它快速定位低分样本（Q1/Q2 的主要来源）
- 如果发现某维度 Q1/Q2 完全没有样本 → 在模板里明确写"该档样本不足"，这类要等研究生复核后补充，不属于你硬凑的范围

---

## 六、工作规范（重要）

1. **数学、英语分开做**，不要混（两科课标、内容都不同）
2. **原文引用必须真实**：只从 JSON 的 `原文引用` 里选，禁止改写、拼接、编造
3. **档位特征要"可判断"**：写完自己读一遍——如果拿掉教案名后看不出说的是哪档，就是不合格
4. **空档位如实标注**："样本不足"不是你的错，数据就这么多
5. **不要改系统代码、不要跑评分**：你只做数据分析与整理（如需跑命令看数据，用只读方式）
