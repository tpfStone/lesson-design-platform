# 部署与使用说明

> 面向师范生与一线教师的使用手册。全程不需要写代码，按步骤操作即可。

---

## 一、这是什么

一个**本地运行的教案评分与批注工具**：导入一份教案（PDF/Word），系统会按照评分标准逐维度打分，并给出批注、依据来源和具体的修改建议。

- 评分依据：评分标准 + 课标要求 + 教学设计理论 + 小学教学法 + 真实教案分数段参照
- 生成产物：批注报告（Word）、已批注教案（PDF）、评分清单（JSON/Markdown）
- 支持两套标准：**竞赛标准**（比赛评审）、**学生标准**（教学能力训练）

---

## 二、安装（只需一次）

### 1. 安装 Python

1. 打开 <https://www.python.org/downloads/> 下载 **Python 3.10 或更高版本**
2. 安装时**务必勾选 `Add Python to PATH`**（这一步最容易漏）
3. 安装完成后，按 `Win + R`，输入 `cmd` 回车，输入 `python --version`，能看到版本号即成功

### 2. 解压项目

把项目文件夹（如 `BiaoZhu`）解压到一个**路径不含中文和空格**的位置，例如 `D:\BiaoZhu`

### 3. 获取 API Key

系统需要调用大模型（DeepSeek）完成评分：

1. 访问 <https://platform.deepseek.com/> 注册账号
2. 在「API Keys」页面创建一个 Key（形如 `sk-xxxxxxxx`）
3. 复制保存好（只显示一次）

> 费用说明：按量计费，评一份教案约几分钱到一毛钱。

---

## 三、启动（每次使用）

**双击项目根目录下的 `start_web.bat`**

- 首次运行会自动安装依赖（约 2-5 分钟），请耐心等待
- 成功后会自动打开浏览器，地址为 <http://localhost:8501>
- 使用结束后，关闭那个黑色命令行窗口即可停止

如果双击后一闪而过，右键选择「以管理员身份运行」，或手动打开 cmd 执行：

```
cd /d D:\BiaoZhu
start_web.bat
```

---

## 四、开始评分

### 第 1 步：填写 API Key

浏览器打开后，进入左侧「⚙️ 设置」，把 API Key 粘贴进去，点「保存到本次会话」。

> 关闭浏览器后需要重新填写（出于安全考虑不会写入文件）。

### 第 2 步：准备教案

两种方式任选：

- **方式 A（推荐）**：把教案文件放到 `data\plans\` 文件夹，然后在「📝 教案评分」页从下拉列表选择
- **方式 B**：在「📝 教案评分」页选择「上传新文件」，直接上传 PDF 或 Word

> 文件要求：文本型 PDF 或 DOCX。
> 如果是**扫描版/拍照型 PDF**，系统会自动做文字识别（OCR），速度较慢（约 10 秒/页），且可能有个别识别误差。

### 第 3 步：选择评分标准并开始

- **评分标准**：竞赛标准 / 学生标准
- **提示词变体**：一般保持 `default` 即可
- **生成细化建议**：建议勾选（会多花约 40 秒，但能拿到"怎么改"的具体建议）

点击「🚀 开始评分」，等待约 2 分钟。

### 第 4 步：查看结果与下载

结果页会显示：

- **总分**与各维度得分（含条形图）
- **每个维度的批注明细**：位置 → 原文引用 → 分析 → 诊断 → 依据来源 → 教学法参考 → 细化建议
- **下载**（产物数量取决于教案格式）：

| 教案格式 | 可下载的产物 |
|---------|------------|
| **PDF**（文本版或扫描版） | 批注报告 DOCX、**已批注 PDF**（原文高亮+批注气泡）、评分清单 JSON/MD |
| **Word（DOCX）** | 批注报告 DOCX、**已批注 Word**（Word 原生批注气泡）、评分清单 JSON/MD |

> 💡 **两种"已批注"文件有什么区别？**
> - **已批注 PDF**：在原始 PDF 上高亮原文 + 批注气泡
> - **已批注 Word**：在你上传的 `.docx` 上添加 Word **原生批注**（右侧批注栏），支持 Word 的"回复 / 标记已解决 / 导出批注"等功能
> - 两者都保留原文档排版，用 Word 或 PDF 阅读器直接打开即可

## 五、复核标注（用于人工校准）

系统评分是"AI 初评"，建议人工复核后使用。进入「🔍 复核标注」：

1. 选择一份评分结果
2. 在**维度级复核**表里填写"复核得分"（留空表示认可系统分）
3. 在**批注级复核**表里修正评价等级（如把"基本达标"改为"部分达标"）
4. 点「💾 保存复核结果」

复核记录保存在 `output\review\`，包含系统分与复核分的差异，可用于统计模型准确度、校准评分尺度。

## 六、批量评分与对比

「📊 批量与对比」页：

- **批量评分**：多选教案 → 一次全部评完（每份约 2 分钟，请留足时间）
- **结果对比**：查看所有已评教案的总分表，一键生成横向对比表（Markdown）

## 七、常见问题

| 问题 | 解决办法 |
|------|---------|
| 双击 bat 后没弹出网页 | 先等 10 秒（启动需要时间）；若仍没有，手动在浏览器地址栏输入 `http://localhost:8501` |
| 提示"服务已经在运行" | 说明已有一个窗口在跑，直接访问 `http://localhost:8501` 即可 |
| 双击 bat 一闪而过 | 右键「以管理员身份运行」；若仍失败，打开 cmd 执行 `cd /d 项目路径` 后再运行 `start_web.bat` 查看报错 |
| 提示 `python 不是内部或外部命令` | Python 未加入 PATH，重新安装并勾选 `Add Python to PATH` |
| 提示 API Key 未配置 | 到「⚙️ 设置」页填写，或重启 bat 后重新填写 |
| 首次启动卡在 "Welcome to Streamlit! Email:" | 已修复：bat 会自动创建跳过该引导的配置文件；若仍出现，直接回车跳过 |
| 评分失败/超时 | 检查网络；大模型服务偶发波动，重试即可 |
| 扫描版 PDF 特别慢 | 属正常（逐页 OCR）。若不需要，改用文本版 PDF |
| 中文显示成乱码（命令行） | 不影响网页使用；请确认 Windows 区域设置为「中文(简体)」 |
| 想换模型（更快/更准） | 编辑 `config.yaml` 中 `llm.model`：`deepseek-v4-flash`（快）或 `deepseek-v4-pro`（准） |

## 八、目录说明

```
BiaoZhu/
├── start_web.bat          ← 双击启动
├── config.yaml            ← 配置（模型、目录、锚点开关）
├── requirements.txt       ← 依赖清单
├── web/app.py             ← Web 界面
├── data/
│   ├── plans/             ← 放入待评教案
│   ├── criteria/          ← 评分标准文件
│   └── examples/          ← 标注示例（Few-Shot）
├── knowledge_base/        ← 知识库（课标、教学法、锚点）
└── output/                ← 评分产物
    ├── competition/       ← 竞赛标准结果
    ├── student/           ← 学生标准结果
    └── review/            ← 人工复核记录
```

## 九、使用建议

1. **先小范围试用**：选 2-3 份熟悉的教学设计，对比系统分数与自己/导师的判断，感受一下评分尺度
2. **务必人工复核**：系统评分作为初评参考，最终结论由人确定
3. **关注"依据来源"**：每条批注都标注了依据（课标原文 / 设计理论 / 教学法），可直接用于教学设计的修改说明
4. **反馈问题**：如果发现评分明显不合理，请记录教案名 + 维度 + 你的判断，反馈给维护者用于优化
