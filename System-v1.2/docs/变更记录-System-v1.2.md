## 二、逐项说明

### 1｜科目识别误判修复
- **问题**：英语教案被识别为数学（如《Unit3 weather PartB Let's talk》）
- **根因**：`detect_subject()` 为「先命中先返回」，且数学关键词含大量泛化词（图形/加法/乘法/数一数）
- **修复**：改为**加权计分制**
  - 文件名命中 ×2；专有词 3（如 `人教版数学`、`PEP`、`Unit`）/ 学科术语 2（`口算`、`Let's talk`）/ 泛化词 1（`图形`、`加法`）
  - 同分时先比专有词命中数，再按固定优先级
  - 辅助信号：外文占比 > 20% 且英语已有基础分 → 英语 +3
  - 新增 `detect_subject_detail()`（输出各科得分明细，便于排查）
- **验证**：现有 41 份教案 **41/41 正确、0 误判**；构造测试 **8/8**（含"英语课提及图形/加法/乘法"）

### 2｜扫描版 PDF 三层友好提示
- **问题**：上传扫描版 PDF 时抛出 `ModuleNotFoundError: No module named 'easyocr'`（用户看不懂）
- **修复**（三层防护）：
  1. `parsers.py`：新增 `ocr_available()` / `is_scanned_pdf()` / `check_ocr_ready()`；解析遇扫描版无 OCR 时抛**友好说明**
  2. `service.py`：评分前 `check_ocr_ready` 前置检查 → 友好中文提示（含安装指引）
  3. `web/app.py`：评分页检测后显示**黄色警告 + 禁用评分按钮**；批量页预检并列出受影响文件
- **验证**：`is_scanned_pdf` 判定准确（26 份 PDF → 8 扫描版 / 18 文字版）；模拟未装 OCR 时返回友好文案 ✓；docx 不受影响 ✓

### 3｜评分标准与提示词固定

- `config.yaml`：`default_criteria: "student"` + 新增 `default_variant: "v2_guided"`

### 4｜OCR 安装与使用全流程
- 新增 **`docs/OCR安装与使用说明.md`**（含：是否需要装的判断方法 / **去哪装** / **装到哪**（多 Python 环境的坑）/ **怎么用** / 体积耗时 / 6 条常见问题 / 卸载）

### 5｜批注等级：五档 → A/B/C
- **设计**：不再由模型输出等级，改由**系统按维度得分换算**（稳定、可复现）
- `standards.py` 新增 `GRADE_BANDS` + `score_to_grade()`，区间**严格取学生标准原文**：

| 维度满分 | A | B | C |
|:---:|:---:|:---:|:---:|
| 5 分制 | 4-5 | 2-3 | 0-1 |
| 10 分制 | 8-10 | 5-7 | 0-4 |
| 20 分制（过程设计）| 14-20 | 7-13 | 0-6 |

- `prompts.py`：去掉"评价"字段要求（模型不再输出等级）
- `service.py`：`apply_grades_and_tree()` 为每个维度标注等级、每条批注 `评价` = 所属维度等级
- `suggester.py`：触发条件改为「A 档跳过；B/C 生成改进建议」（兼容历史五档）
- `annotator.py` / `pdf_annotator.py`：颜色与 emoji 映射改为 A 绿 / B 橙 / C 红
- **验证**：`score_to_grade` 单测 **16/16**（覆盖三种分制边界）；端到端产物仅出现 A/B/C ✓

### 6｜一级维度分组
- `standards.py` 新增 `LEVEL1_TREE` / `DIM_TO_LEVEL1` / `get_level1()` / `group_by_level1()`
- 一级 → 二级映射（源自学生标准）：

| 一级维度（满分） | 二级维度（满分） |

| 思想理念（10） | 教学理念(5)、课程思政(5) |
| 学情与目标分析（10） | 学情分析(5)、教学目标(5) |

| 评价反馈（10） | 评价反馈(10) |
| 文档规范（10） | 版式观感(5)、结构完整(5) |

- **产物**：批注报告 DOCX 的评分总表改为「一级维度 | 二级维度 | 满分 | 得分 | 等级」（一级含小计行）；详细批注改为**一级维度作章节、二级维度作小节**
- **JSON**：`评分汇总.一级维度汇总`（含二级维度明细）

### 11｜维度雷达图（归一化）
- 样式：**ECharts / Excel 经典样式** —— 5 层多边形网格 + 轴线 + 轴刻度值 + **无填充折线 + 实心圆点 + 点值标注**
- 数据：**归一化得分率**（得分÷满分×100），使 5/10/20 分维度可同图比较
- 交互：悬停显示（教案/维度/得分率）；勾选框控制是否显示点值（≤3 份默认开）
- 支持视图切换：`📋 横向对比表` / `🕸️ 维度雷达图`
- **依赖**：Altair（随 Streamlit 自动安装，无需额外安装）
- **样式修正（同日迭代）**：
  1. **网格多边形不闭合** → 为网格层显式指定 `order`（连线顺序）通道。
     原因：Vega-Lite 的 line mark 在缺少 `order` 时**会按 x 值自动排序**，而多边形顶点在 x 上左右对称重复，
     排序后顶点顺序错乱、画不闭合。修复后五层网格（含最外 12 边形）全部完整闭合。
  2. **全屏时被拉伸变形** → 图表尺寸固定为 **620×620（正方形）**，渲染由 `width="stretch"` 改为
     `width="content"`，并注入 CSS 使图表**居中显示**。原因：雷达图依赖等比例坐标轴，宽度随容器变化而高度固定
     会导致纵横比改变、图形被拉扁；固定尺寸后若仍左对齐，全屏时右侧会留大片空白，故一并居中。
     （尺寸由 440 调至 620，使全屏宽度下界面更协调。）
