# 教案智能批注系统 — 设计思路与功能说明

---

## 一、设计思路

做这套系统的出发点很简单：**给一份教案打分和批注，是件费时又费脑的事，而且不同人评出来的结果差异很大。**

人工评审一份教案，通常要经历这几步：先整体读一遍，判断教案属于什么学科、面向几年级；再对照评分标准，看教学理念、目标、过程设计这些维度做得怎么样；遇到问题还要想清楚"问题是什么、为什么、怎么改"；最后才形成一份评语。

这套系统做的就是**把上述过程自动化**，而且尽量模拟一位有经验的评审专家，而不是简单套模板。

### 一条主线：让 AI"学专家怎么评，再照着评"

系统没有靠一句"请评价这份教案"的通用提示词，而是采用**标注示例驱动（Few-Shot）**的思路：

1. 先给 AI 看几份**已经人工标注好的教案**（示例里包含评语风格、扣分逻辑、批注方式）；
2. 让 AI 从示例中**学思路、不抄内容**——示例和新教案可能来自不同学科、不同年级，重点学的是"从什么角度切入、证据怎么引用、语气怎么拿捏"；
3. 再让 AI 用同样的思路去批注新教案。

这样做的效果是：**评分的"口味"是可以定制的**——换一批示例，评分风格就会跟着变，而不是永远一套大而空的模板。

### 让评分"有依据"而不是"凭感觉"

光让 AI 模仿示例还不够，评分必须站得住脚。系统为每次评分注入两类"参照系"：

- **设计理论库**：收录 ADDIE 模型、布鲁姆目标分类、逆向设计（UbD）、ARCS 动机模型等 36 条教学设计理论。批注指出问题后，自动匹配相关理论作为支撑。
- **课标标准库**：将 2022 版《义务教育数学课程标准》《英语课程标准》按学段（1-2/3-4/5-6/7-9 年级）结构化整理成知识库。系统从教案中识别年级，把该学段应达到的课标要求注入评分过程，判断教学内容是否"该学的没学、不该学的超前教"。

### 诊断与处方分开写

批注里最忌讳一句话把"问题和改法"糊在一起，AI 很容易写出"建议改进教学目标的表述，使其更加具体"这种正确的废话。

系统把批注拆成两半：

- **建议（诊断）**：1-2 句话点明核心问题——"目标使用'了解''掌握'等模糊动词，无法判断学生达成度。"
- **细化建议（处方）**：给出具体改法，教师照着就能改——"将'了解分数的意义'改为'能结合直观模型说出 3/4 的含义，并用分数表示图中阴影部分'。"

诊断归诊断，处方归处方，评语才真正有用。

### 最后：把批注"画"到教案上

文字评语之外，系统还会在原 PDF 上做可视化批注：问题句子高亮显示，旁边挂便签写评语，翻到附录还有改进建议汇总。导师或作者拿到手，翻开就能看到"哪里有问题、问题是什么、怎么改"。

## 二、功能说明

### 1. 教案批注（核心功能）

输入一份教案 PDF 或 Word，系统自动完成：

- **学科识别**：从文件名和正文判断学科（数学、英语、信息科技等）
- **标准匹配**：自动选择对应学科的评分标准
- **全维度评分**：按 12 个维度打分（教学内容、教学理念、学情分析、教学目标、教学资源、教学方法、过程设计、课程思政、课堂互动、评价反馈、版式观感、文档规范），满分 100
- **逐条批注**：每条批注包含 位置 → 原文引用 → 评价等级 → 问题分析 → 建议（诊断）→ 依据来源 → 细化建议（处方）

### 2. 批注 PDF 生成

在原教案 PDF 上直接标注：

- 问题原文**高亮**
- 相邻位置自动避开重叠，改用**便签**
- 原文找不到时用**兜底便签**并注明
- 末尾**附录页**汇总全部批注与改进建议

### 3. 评分标准切换

两套标准一键切换，同一份教案可分别按不同标准评估：

- **竞赛标准（competition）**：如"田家炳杯"数学/英语/信息科技评价参考标准
- **学生自制标准（student）**：学生课堂评价指标

### 4. 知识库构建

系统内置两个可扩展的知识库：

| 知识库 | 内容 | 来源 |
|--------|------|------|
| 设计理论知识库 | 36 条教学设计理论，7 大类 | 教学设计理论文档自动解析 |
| 课标标准库 | 数学 80 条、英语 77 条学段要求 | 课标 PDF → OCR → LLM 结构化 |

新增课标、理论或评分标准文件放进对应目录即可，无需改代码。

### 5. 课标对照

自动识别教案年级（支持"四年级""五年"等中文/数字写法），映射到课标学段，把该学段应达到的要求注入评分，用于判断教学内容是否超前、滞后或漏项。年级识别不到时自动跳过，不影响主流程。

### 6. 改进建议生成

对每条非"达标"批注：

- 同时检索**设计理论**和**课标原文**，标注依据来源类型（设计理论 / 课标标准 / 二者共同）
- 批量生成"细化建议"（一次调用完成，稳定不卡顿）

### 7. 批量处理与横向对比

- 一次跑完 `data/plans/` 下所有教案
- 自动按学科分组生成**横向对比表**（MD + CSV，Excel 可直接打开），同组教案各维度得分一目了然

### 8. 输出产物（每份教案一套）

| 产物 | 用途 |
|------|------|
| 批注报告 `.docx` | 完整评审报告，可打印/提交 |
| 已批注 `.pdf` | 原文可视化标注，直观展示问题位置 |
| 评分清单 `.json` | 结构化数据，便于二次处理与对比 |
| 评分清单 `.md` | 可读版评分明细 |
| 对比表 `.md/.csv` | 批量模式下同组教案横向对比 |

### 9. 调试辅助

- `--dry-run`：只构建提示词不调用模型，便于排查提示词问题
- 每次运行保存完整提示词到 `debug_prompt.txt`
- 三种提示词变体可切换（平衡 / 引导 / 严格），适应不同评审风格

## 三、典型使用流程

```
把教案放进 data/plans/
        ↓
python pipeline.py --batch --criteria competition --suggest
        ↓
output/教案名/
  ├─ 教案名_批注报告.docx
  ├─ 教案名_评分清单.json / .md
  ├─ 教案名_已批注.pdf
  └─ batch_comparison.md / .csv   （批量对比表）
```
