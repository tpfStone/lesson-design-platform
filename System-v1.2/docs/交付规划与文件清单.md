## 一、系统概况

| 项目 | 内容 |
|------|------|
| **系统名称** | 教案智能批注系统（Few-Shot 标注示例驱动） |
| **核心理念** | LLM 从"已标注示例"中学习标注思路，模仿标注新教案并评分 |
| **支持学科** | 数学、英语（架构上可扩展到其他学科） |
| **评分标准** | 竞赛标准（田家炳杯）、学生自制标准（可切换） |
| **使用形态** | ① 本地 Web 界面（Streamlit，5 个页面） ② 命令行（pipeline.py） |
| **技术栈** | Python 3.12 + Streamlit + DeepSeek API + PyMuPDF + python-docx |
| **代码规模** | 顶层 20 个模块 + Web 1 个 + 工具 11 个（约 5000 行） |
| **数据资产** | 课标库（数学/英语结构化）、设计理论库 36 条、小学教学法库、锚点库（数学 40 档位/英语 42 档位） |

**核心流程**：
```
标注示例 + 评分标准 → 提示词构建（含锚点档位参照）→ LLM 评分（12 维度 + 逐条批注）
→ 三库检索生成改进建议 → 产物（批注报告/已批注文件/评分清单）
```
